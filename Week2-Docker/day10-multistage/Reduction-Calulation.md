<h3>Image Size Comparison</h3>

<p>Write down the measured sizes of both images.</p>

<ul>
  <li><strong>Single-stage image:</strong> 1310 MB</li>
  <li><strong>Multi-stage image:</strong> 19 MB</li>
</ul>

<h3>Calculate Image Size Reduction</h3>

<p>Use the following formula:</p>

<p><strong>Reduction (%) = ((Single-stage size − Multi-stage size) / Single-stage size) × 100</strong></p>

<p><strong>Example calculation:</strong></p>

<p>Reduction (%) = ((1310 − 19) / 1310) × 100</p>

<p>Reduction (%) = (1291 / 1310) × 100</p>

<p><strong>Reduction ≈ 98.55%</strong></p>

<p>This means the multi-stage image is approximately 98.55% smaller than the single-stage image.</p>
